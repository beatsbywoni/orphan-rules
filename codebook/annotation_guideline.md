# Annotation Codebook — v1.1 (2026-08-15)

*English abstract.* This codebook governs three annotation tasks: (A) clause-level delegation labelling on a 200-item probability-sampled calibration set (L1–L4); (B) normative-character triage of rule-level orphan candidates (T1–T2); (C) reading of screened court decisions as a correctness oracle (O1–O8). All labels, memos, and adjudication records are released in `data/labels/`. Version 1.1 (post author-labelling, pre LLM run) added the value `교육규칙` to L2 and the multi-form notation; the judgement criteria themselves were unchanged.

---

## A. 위임조항 라벨 (goldset, L1~L4)

판정 대상은 `조문문장` 열의 **문장 하나**이다. 상위법령명·조문번호는 맥락 참고용.

### L1_위임인가 — 이 문장이 하위 규범에 규율권한을 넘기는가

| 값 | 기준 |
|---|---|
| `위임` | 하위 규범이 정할 사항의 범위를 지시하며 규율권한을 넘긴다 ("…은 대통령령으로 정한다", "장관이 정하는 기준에 따라") |
| `인용` | 다른 법령을 가리키기만 한다 — 정의 원용, "「○○법」에 따른", 준용("제○조를 준용한다"), 개별 처분 권한만 부여 |
| `판단불가` | 문장이 잘렸거나 맥락 없이 판정 불가 |

경계 규칙:
1. 준용 규정 → `인용`
2. 부분 위임("대통령령으로 정하는 ○○"처럼 요건 일부만) → `위임`
3. 규범 제정이 아니라 개별 처분 권한만 부여 → `인용`
4. 포괄위임이 의심되어도 일단 `위임` (위헌성은 판정하지 않는다)
5. **완료형 원용** — "○○령으로 정**한** 기준"(이미 제정된 규범의 지시)은 `인용`,
   "○○령으로 정하**는**"은 `위임`
6. **절단 문장** — 주제어+수단격 조사까지 있어 위임 문형이 완결이면(예: "사항은
   대통령령으로") `위임`, 동사·주제 없는 파편(예: "또는 대통령령으로")은 `판단불가`
7. **법률 유보** — "따로 법률로 정한다"는 하위 규범 위임이 아니다 → `인용`

### L2_위임된법형식 — 문언이 무엇을 요구하는가 (실제 제정 형식이 아님)

`대통령령 / 부령 / 고시 / 훈령 / 예규 / 조례 / 교육규칙 / 미특정 / 해당없음`

- v1.1: `교육규칙`(교육감 제정 자치법규)을 `조례`와 구분한다. 집계 시 두 값은
  자치법규 상위범주로 묶을 수 있다.
- v1.1: **복수 형식 병존** — 한 문장이 복수 형식에 위임하면(예: "대통령령 또는
  조례로", "대통령령으로 정하는 범위에서 조례로") 주 라벨에는 표본 간선의 축을
  기재하고 보조 열 `L2_병존형식`에 나머지를 `|`로 나열한다. LLM 어노테이터는
  병기 형식 전부를 `|`로 나열한다. 일치도는 집합 교집합으로 판정한다.
- `미특정`: "장관이 정하는", "교육감이 지정하는" 등 형식 무지정
- `해당없음`: L1이 `인용`인 경우
- 값 목록 외 형식(학칙·정관·유치원규칙 등)은 보조 열·메모에 기재한다 (v1.2 후보)

### L3_확신도 (1~5), L4_메모

확신도 3 이하는 메모 필수. 판정 기준을 도중에 바꾼 경우 그 시점을 메모.

## B. 고아규칙 트리아지 (T1~T2)

**질문: 이 규칙이 행정조직 바깥의 누군가(또는 소속 공무원 개인의 신분·권리)의
권리·의무·자격·기준에 관계되는 사항을 규율하려 하는가?**

| 값 | 기준 |
|---|---|
| `대외구속지향` | 국민·학생·학부모·사립학교(법인)·민간기관의 권리의무·자격·지정·기준·제재. 수익적 급부의 요건·기준 포함. 소속 공무원·교원 **개인**의 신분·보수·복무상 이익·불이익도 포함(메모에 `신분관계` 태그) |
| `내부관리` | 부처 내부 조직·사무처리·행사 운영. 외부 효과가 없거나 반사적 |
| `판단불가` | 전문을 읽어도 모호 |

경계 규칙:
1. 위원회 설치·운영 규정은 원칙 `내부관리`, 위원회 결정이 외부인의 자격·지정을
   직접 좌우하면 `대외구속지향`
2. 표준 서식 고시는 서식이 의무를 창설하면 `대외구속지향`, 단순 양식 제공이면
   `내부관리` (의무의 창설 주체가 법령이면 후자)
3. 행정권한의 위임·위탁 고시는 별도 태그(`#권한위임고시`)로 분리 집계

## C. 판례 오라클 판독 (O1~O8)

- `O1_무효판단`: `Y`(효력·대외적 구속력 부정) / `부분` / `N`(다뤘으나 유효 —
  false-positive 대조군으로 보존) / `무관`
- `O2_결함유형`: `D1`(위임 부재) / `D2`(형식 불일치 — 대법원 2010다72076 기준)
  / `D3`(재위임 단절) / `기타`(내용적 일탈·포괄위임·절차 하자·헌법원칙 위반)
- `O3`·`O4`: 대상 규정 명칭·일련번호. 폐지·개정으로 현행 코퍼스에 없으면
  메모에 "현행 부존재" (조인 실패를 탐지 실패로 오인하지 않기 위함)
- `O5_메모`: 판정 근거. 상급심 번복·동일 조항 중복은 상호 참조를 남긴다
- `O6_판시유형`: `무효선언` / `구속력부정`(성질결정) / `각하`(대상성 부정) /
  `해석례회신` — **층을 섞어 집계하지 않는다**
- `O7_대상층위`: 행정규칙 / 부령 / 시행령 / 자치법규 / 법률 / 기관내부규정
- `O8_코퍼스관계`: 교육부현행 / 타부처현행 / 폐지·실효 / 범위외

## 조정(adjudication)

제2 어노테이터(LLM)와의 불일치는 저자가 근거를 기록하고 확정한다. 전 건의 조정
기록과 원본 어노테이션을 공개한다 (Braun 2024 권고 ①~⑤ 이행).
