## D-2026-08-18-1 — OpenAI 검사(T4–T6)의 temperature·출력 토큰 파라미터

- **등록 조항**: §2 "temperature 0; max output 300 tokens".

  `reasoning_effort="minimal"`, `max_completion_tokens=1000`으로 실행한다.
  T1–T3(Anthropic)은 등록대로 temperature 0, max_tokens 300.
- **사유**: 제공자 API의 기술적 제약. 등록 §2의 T8 조항과 같은 성격의
  기술적 가용성 문제.
- **영향**: run-to-run self-consistency(500건 × 3회)가 실효 무작위성을
  실측한다. 파라미터 전체는 data/panel/manifest.json에 고정 기록.
